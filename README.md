# Frontend Portfolio

This is a single-folder frontend portfolio for an Information Systems graduate. It is built with plain HTML, CSS, and JavaScript only, without any database or backend setup.

## Folder structure

All project files are kept in one folder at the site root:

- `index.html`
- `about.html`
- `projects.html`
- `contact.html`
- `style.css`
- `script.js`
- `profile.svg`
- `project-placeholder.svg`
- `cv.pdf`
- `README.md`

## Run locally

1. Place this folder inside XAMPP's `htdocs`.
2. Start Apache.
3. Open the site in the browser at:
   - `http://localhost/personal_portfolio/index.html`

## Customize content

Update the text and links directly in the HTML/JS files to match your real information.

## Notes

- This version is frontend-only and does not use a database.
- The portfolio includes dark/light theme support, language switching, and responsive design.
- Replace `cv.pdf` with your real CV file when needed.
